Überblick und Identität

105a:3376 ist ausdrücklich vorhanden und wählt neben anderen eigenständigen IDs board_2037x. Das Controllerpaar beschreibt weder Arraymetadaten noch Laufwerksmodelle oder eine OEM-Kartenanordnung.

Kuratierte Kennungen
pci 105a:3376

Ein numerischer Match belegt eine Kandidatenfamilie im geprüften Quellenrahmen. Verkaufsnamen, Platinenvarianten, Subsystembedingungen und erfolgreiche Funktion bleiben getrennte Fragen.

Treiber und Bindung

sata_promise ist der Upstream-libata-Kandidat. Ein Firmwaremenü mit FastTrak- oder RAID-Bezeichnung zeigt allein nicht, wie Linux die physischen Geräte präsentiert.

  • sata_promise — Kernel-Treiber-/Modulkandidat

Firmware

Geräte- und revisionsabhängig

Lesende Diagnose

Führe jeden angezeigten Befehl einzeln aus. Ersetze Großbuchstaben-Platzhalter durch betroffenes Gerät, Schnittstelle oder Modul aus deiner Ausgabe. Hier wird nichts ausgeführt. Auch lesende Ausgaben können private Kennungen enthalten.

PCI-Funktion und gebundenen Treiber prüfen

lspci -nnk -s BDF

BDF durch die Adresse Domain:Bus:Gerät.Funktion ersetzen. Auf [105a:3376] und Kernel driver in use achten. sata_promise unter Kernel modules ist nur ein Kandidat, kein Bindungsnachweis.

Sichtbare Blockgeräte identifizieren

lsblk -d -o NAME,MODEL,TRAN,HCTL

MODEL beschreibt ein Blockgerät oder ein vom Controller präsentierter logischer Datenträger; es ist keine PCI-Controlleridentität. HCTL unterscheidet SCSI-Ziele. TRAN kann fehlen; die Liste beweist keine vollständige physische Datenträgertopologie.

Controller- und Transportmeldungen lesen

sudo journalctl -k -b --no-pager

Erhöhte Rechte können nötig sein. Root liest das Kerneljournal des aktuellen Starts. Meldungen von sata_promise, Port-/Hostkennungen und Zeitpunkte von Timeouts/Resets dem tatsächlichen Controller zuordnen. Ein Reset allein beweist keinen defekten Datenträger oder Firmwarefehler.

Grenzen und passende Fehlerhilfen

Controllererkennung belegt weder ein vollständiges altes Array noch ein sicheres Importverfahren. Die lesende Controlleridentifikation dieses Profils von RAID-Zusammenstellung und Dateisystemreparatur trennen.

Diese Anleitungen passen zu relevanten Befunden und behaupten keinen Fehler bei jedem Gerät dieser Familie.
