Wie funktioniert das lokale Experiment?

wllama berechnet ein quantisiertes Qwen-Modell auf deinem Gerät in einem Worker. Du entscheidest, wann es von dieser Website geladen wird. Soweit unterstützt, werden nur Modelldateien im privaten Browserspeicher dieser Domain zwischengespeichert; der Browser darf sie entfernen. Ohne diesen Speicher gilt der Download nur für die Sitzung. Chatverläufe werden weder gespeichert noch hochgeladen. Hardwareunterstützung und Antwortqualität variieren; die CPU kann langsam sein. Nur ein kleiner jüngerer Gesprächsausschnitt passt in den Kontext. Der experimentelle WebGPU-Pfad kann auf die CPU zurückfallen. Regional geprüftes Platt und eine tägliche Wortsammlung folgen später.
