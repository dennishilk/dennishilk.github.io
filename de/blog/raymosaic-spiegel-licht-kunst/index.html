RAYMOSAIC: 448 kleine Spiegel. Eine ganz persönliche Nachricht.

Von Dennis Hilk17. Oktober 20267 Minuten Lesezeit
Echte lokale Berechnung statt Bilderdienst

Text, Zeichnungen, Spiegel-Einstellungen und Exporte bleiben im Browser, solange du nicht bewusst eine Datei oder einen Link teilst. Kein Konto, keine Analyse-Skripte und keine externe Bildverarbeitung.

Ein Name aus Licht, geformt von Hunderten Spiegeln. RAYMOSAIC ist mein Browser-Experiment, das Optik greifbar machen soll: Namen eingeben, die Ausrichtung der simulierten Spiegel beobachten und das Ergebnis als animiertes GIF verschicken.

Die Idee: Eine kleine Nachricht zum Verschicken

Das Erlebnis beginnt mit einer einfachen Eingabe. Schreib einen kurzen Namen, klicke auf Erstellen und beobachte, wie 448 einzelne Spiegel ihre reflektierten Strahlen zu einer lesbaren Projektion bündeln. Über die schnelle GIF-Aktion entsteht direkt eine kompakte Animation; im Exportdialog stehen weitere Formate und Dauern bereit.

Das sollte ein kleines Geschenk werden und kein kompliziertes Zeichenprogramm. Wer tiefer einsteigen möchte, kann sich trotzdem die gesamte 3D-Anlage ansehen. Zuerst zählt der einfache kreative Moment.

\n

Dahinter steckt tatsächlich eine Reflexionsrechnung

Jede der 28 × 16 Spiegelflächen besitzt eine Position und Ausrichtung. RAYMOSAIC berechnet aus der gewünschten Form, wie jeder Spiegel stehen muss, damit das Licht einer idealisierten Punktquelle auf die Projektionswand trifft.

Der unabhängige Vorwärtsdurchlauf verwendet die Reflexionsgleichung r = i − 2(i · n)n. Dabei bezeichnet i den einfallenden Strahl und n die Spiegelnormale. Gezeichnet wird die Wand aus tatsächlichen Strahlschnittpunkten. Der ursprüngliche Schriftzug wird also nicht als Textur auf die Wand kopiert.

Verschiebst du die Lichtquelle, ohne die Spiegel neu zu berechnen, zerfällt das Muster. Die Spiegel sind noch auf die vorherige Lichtposition ausgerichtet. Mit Spiegel neu ausrichten wird die Geometrie aktualisiert. Zusätzlich lassen sich Strahlen einblenden und einzelne Spiegel untersuchen.

\n

Vom Namen zum animierten GIF

Im Reiter Text passen bis zu 13 Zeichen. Kurze Namen sind wegen der begrenzten Zahl an Spiegeln meist besser erkennbar. Die schnelle GIF-Geschenkaktion verwendet eine kleine Auflösung und eine kurze Schleife, damit die Verarbeitung auf Smartphones praktikabler wird.

PNG speichert ein Standbild. Für GIF berechnet ein Browser-Worker die einzelnen echten Animationsbilder; Fortschritt und Abbruch bleiben verfügbar. Unterstützt der Browser das Teilen von Dateien, lässt sich das GIF an das native Teilen-Menü übergeben. Ansonsten kannst du es herunterladen und als normale Datei versenden. Messenger wie WhatsApp behandeln GIFs nicht überall gleich. Eine identische Vorschau auf jedem Gerät kann ich daher nicht versprechen.

\n

Projekt sichern, wieder öffnen oder als Link teilen

Eine versionierte JSON-Projektdatei speichert das Motiv, die Zeichenmaske, Lichtposition, Kamera, Lichtfarbe und Spiegelausrichtungen. Sie lässt sich später unabhängig vom lokalen Browser-Speicher wieder einlesen.

Kleinere Motive kann RAYMOSAIC komprimiert im Fragment einer URL unterbringen. Empfänger können sie ohne Konto rekonstruieren, und zum Erstellen dieses Links muss die Zeichnung nicht auf einen Server hochgeladen werden. Wird der Link zu lang, ist die Projektdatei der bessere Weg. Wichtig bleibt: Jeder mit dem Link kann den enthaltenen Inhalt sehen.

\n

Was die Simulation leistet und was nicht

RAYMOSAIC ist ein Lernlabor für geometrische Optik, kein industrielles Lichtberechnungsprogramm. Die Quelle ist punktförmig, die Spiegel sind idealisierte ebene Flächen und das Leuchten wird anschaulich dargestellt. Beugung, Polarisation, Abschattung zwischen Spiegeln, globale Beleuchtung und wellenlängenabhängige Materialeigenschaften sind nicht enthalten.

Diese bewusste Vereinfachung macht das Verhalten nachvollziehbar und den Betrieb auf einer statischen Website möglich. Quelloffen sind auch die optische Mathematik, der Canvas-2D-Renderer und der GIF-Encoder.

\n

RAYMOSAIC ausprobieren

Öffne das interaktive RAYMOSAIC-Lichtlabor, schreibe einen kurzen Namen und verschicke ein bisschen Licht. Im RAYMOSAIC-Repository auf GitHub findest du den Quellcode, Beispiele, Architekturhinweise und Tests.
