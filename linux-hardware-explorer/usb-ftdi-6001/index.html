Overview & identity

The upstream table resolves FTDI_VID and FTDI_8U232AM_PID to 0403:6001. This identifies a supported USB identity, not a verified cable brand, authenticity or every chip revision using it.

Curated identifiers
usb 0403:6001

A numeric match establishes a candidate family within the reviewed evidence. Marketing names, board variants, subsystem conditions and successful operation remain separate questions.

Driver & binding

ftdi_sio handles serial interfaces through the USB serial core, typically producing a ttyUSB node. Interface binding and permissions on the resulting tty are separate from recognizing the VID/PID.

Read-only diagnostics

Run one displayed command at a time. Replace uppercase placeholders with the affected device, interface or module from your own output. Commands are never executed here. Read-only output can still contain private identifiers.

Locate the exact USB identity

lsusb -d 0403:6001

This read-only usbutils query normally needs no sudo. The bus/device number locates the USB function but does not establish an exact marketed product or active serial-interface driver.

Read one USB interface driver link

readlink /sys/bus/usb/devices/INTERFACE/driver

Replace INTERFACE with an existing interface such as 1-2:1.0, not only the whole-device name 1-2. This reads a symlink without sudo; a missing link leaves binding unconfirmed.

Inspect serial-port device ancestry

ls -l /sys/class/tty/ttyUSB*/device

Read symlinks without opening a tty or sending bytes. Existing paths can associate a ttyUSB node with its USB interface; an empty glob means no matching ttyUSB path was found.

Limitations & related issues

USB identity cannot prove the electrical voltage level, wiring or connected target. Never open a console or transmit bytes merely to test a driver match; this profile only lists binding and tty associations.
