Aquantia/Marvell AQC107

The AQC107 copper controller is an atlantic device. Multi-rate copper capability and the PCIe host connection are separate links, so both can limit a real transfer independently.

Overview & identity

The driver-local vendor constant is 1d6a and AQC107 is 07b1. The source distinguishes AQC107S and other Aquantia IDs rather than identifying all atlantic devices as AQC107.

Curated identifiers
pci 1d6a:07b1

A numeric match establishes a candidate family within the reviewed evidence. Marketing names, board variants, subsystem conditions and successful operation remain separate questions.

Driver & binding

The atlantic PCI table maps this identity to its hardware revision operations. The upstream guide demonstrates ethtool driver/firmware reporting and separate supported, advertised and current speed fields.

  • atlantic — kernel driver/module candidate

Firmware

Device/revision dependent

The guide shows adapter firmware-version reporting. The inspected PCI table does not establish a universal host-loaded firmware filename for AQC107; resident firmware and board-specific provisioning remain separate.

Read-only diagnostics

Run one displayed command at a time. Replace uppercase placeholders with the affected device, interface or module from your own output. Commands are never executed here. Read-only output can still contain private identifiers.

Check the PCI function and bound driver

lspci -nnk -s BDF

Replace BDF with the domain:bus:device.function address. Look for [1d6a:07b1] and Kernel driver in use. atlantic in Kernel modules is only a candidate, not proof of binding.

Identify the network interface driver

ethtool -i INTERFACE

Replace INTERFACE with the real interface name. Driver and bus-info connect this interface to its device. A displayed firmware-version is adapter information; it does not prove a file was loaded. Candidate: atlantic.

Compare supported modes with the current link

ethtool INTERFACE

Supported/advertised link modes describe capability or negotiation offers. Speed, Duplex and Link detected describe the current link, not measured throughput. An unsupported query is a limitation of the interface/driver.

Separate PCIe transport from Ethernet speed

sudo lspci -vv -s BDF

Elevated access may be needed. Root can expose the full PCI configuration. If PCIe capabilities exist, compare LnkCap with LnkSta: maximum and negotiated PCIe speed/width are different from Ethernet speed. Legacy PCI or virtual functions may omit these fields.

Limitations & related issues

The example output in a guide is not a benchmark or a firmware prescription for this board. Cable quality, switch negotiation and PCIe LnkSta all require actual observations.
