Overview & identity

1102:0002 matches the checked EMU10K1 entry. Related Audigy identities have different PCI IDs; this pair alone does not select an exact Sound Blaster board or its connector layout.

Curated identifiers
pci 1102:0002

A numeric match establishes a candidate family within the reviewed evidence. Marketing names, board variants, subsystem conditions and successful operation remain separate questions.

Driver & binding

snd_emu10k1 is the family candidate and supports a richer internal mixer/DSP route than a simple single-output PCM device. A present ALSA card can coexist with muted or unintended playback routing.

  • snd_emu10k1 — kernel driver/module candidate

Read-only diagnostics

Run one displayed command at a time. Replace uppercase placeholders with the affected device, interface or module from your own output. Commands are never executed here. Read-only output can still contain private identifiers.

Inspect the PCI function and binding

lspci -nnk -s BDF

Replace BDF with the complete address, for example 0000:00:14.0. This read-only query needs pciutils and normally no sudo. “Kernel driver in use” is observed binding; “Kernel modules” lists candidates.

List kernel ALSA cards

cat /proc/asound/cards

Read the current ALSA card list without sudo. Card indexes can change after reboot; an existing card does not yet establish the selected desktop output or usable wiring. A missing file can also reflect unavailable procfs/ALSA support.

List playback PCM endpoints

aplay -l

This read-only alsa-utils listing normally needs no sudo and does not play audio. Compare card/device numbers with the card list; a PCM endpoint is separate from a PipeWire profile and mixer state.

Limitations & related issues

The ID table establishes a candidate, not tested surround, MIDI or digital output compatibility. Board-specific connectors and actual mixer state remain runtime questions.
