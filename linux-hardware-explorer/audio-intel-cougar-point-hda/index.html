Overview & identity

The HDA_CPT constant resolves to 1c20 for vendor 8086. The controller ID does not reveal whether the attached codec is Realtek, another vendor, or which motherboard jack is connected.

Curated identifiers
pci 8086:1c20

A numeric match establishes a candidate family within the reviewed evidence. Marketing names, board variants, subsystem conditions and successful operation remain separate questions.

Driver & binding

snd_hda_intel is the checked PCI controller candidate; codec drivers build the controls and PCM routes above it. First distinguish controller binding, codec enumeration, ALSA endpoints and desktop output selection.

  • snd_hda_intel — kernel driver/module candidate

Firmware

Conditional firmware path

The controller source supports an optional user-specified HDA patch file. No mandatory external firmware filename was established for this PCI identity.

Read-only diagnostics

Run one displayed command at a time. Replace uppercase placeholders with the affected device, interface or module from your own output. Commands are never executed here. Read-only output can still contain private identifiers.

Inspect the PCI function and binding

lspci -nnk -s BDF

Replace BDF with the complete address, for example 0000:00:14.0. This read-only query needs pciutils and normally no sudo. “Kernel driver in use” is observed binding; “Kernel modules” lists candidates.

Read HDA codec descriptions

cat /proc/asound/card*/codec*

Read available HDA codec proc files without changing mixer controls. Normally no sudo is required. Codec vendor/subsystem IDs are HDA identities and must not be interpreted as the PCI controller VID/DID; unavailable proc entries leave this layer unknown.

List kernel ALSA cards

cat /proc/asound/cards

Read the current ALSA card list without sudo. Card indexes can change after reboot; an existing card does not yet establish the selected desktop output or usable wiring. A missing file can also reflect unavailable procfs/ALSA support.

Limitations & related issues

The PCI match does not establish a working microphone or speaker route. The source supports optional administrator-selected HDA patch firmware, but no default patch filename is implied for this controller.
