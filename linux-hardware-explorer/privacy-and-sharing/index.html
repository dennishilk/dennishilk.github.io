Private reports and public hardware links

Separate temporary local report analysis from shareable device profiles, diagnostic summaries and redacted excerpts.

2026-10-10Share this explanation

Reports stay in this tab

The Explorer parses text in a local Web Worker and uses the shipped catalog. There is no report upload, AI service, account or report storage. Clearing the tool or leaving the page discards the input and result state. Changing language preserves only allowed public catalog and diagnostic identifiers; it discards raw device metadata.

The default summary is an allowlist

The default export includes catalog profile links and recognized driver names, not raw labels, BDF addresses, hostnames, serials, MACs or report lines. Numeric chip IDs can be included by an explicit local option. A separately requested redacted excerpt is best effort and must be reviewed before it is sent elsewhere; unusual identifiers can evade automatic redaction.

Sharing opens a draft you control

Share buttons refer to public device or explanation pages. They never attach the pasted report. Mastodon, X and Facebook open their own site; native sharing depends on your browser. Nothing is posted automatically. A user-edited share message can contain anything you type, so review it before submitting on the destination platform.
