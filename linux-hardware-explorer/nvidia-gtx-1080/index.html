Overview & identity

10de:1b80 is the unqualified GTX 1080 row checked in the versioned NVIDIA list. Other rows describe mobile and OEM variants; this profile does not extend the exact match to them or infer a laptop from a shortened GTX 1080 name.

Curated identifiers
pci 10de:1b80

A numeric match establishes a candidate family within the reviewed evidence. Marketing names, board variants, subsystem conditions and successful operation remain separate questions.

Driver & binding

For a proprietary-driver system, retain the kernel-module version and installed userspace version together. A driver/library mismatch is an installation-state observation, whereas an Xid bus-loss event concerns runtime access to the GPU. Nouveau as the current owner can be intentional and is not automatically a conflict.

Read-only diagnostics

Run one displayed command at a time. Replace uppercase placeholders with the affected device, interface or module from your own output. Commands are never executed here. Read-only output can still contain private identifiers.

Read the numeric PCI identity and binding

lspci -nnk -s BDF

Replace BDF with the address of the GeForce GTX 1080 display function. No sudo is normally required for this summary. The numeric vendor/device pair is the evidence for identity; “Kernel driver in use” is evidence of the current binding. A “Kernel modules” list is only a list of candidates.

Confirm the owner of this PCI function

readlink /sys/bus/pci/devices/BDF/driver

Use the full domain:bus:slot.function address in BDF, for example the form shown by lspci -D. This read-only symlink normally needs no elevated privileges. Its last component names the bound driver. An absent link can also mean an unbound, removed or guest-assigned function; it does not prove that no Linux driver exists.

Read initialization and failure context

journalctl -k -b --no-pager

Keep nvidia/NVRM and Nouveau messages separate and correlate them with the selected PCI function; an Xid is a runtime error report, not a driver-installation verdict. This reads the current boot only. Correlate the PCI address and timestamps before connecting a message to this GPU. Journal access depends on local group permissions; a permission error is not a hardware result.

Read the vendor-driver userspace observation

nvidia-smi --query-gpu=pci.bus_id,name,driver_version --format=csv

This read-only query requires the NVIDIA userspace utility and a working NVIDIA driver connection, but normally no sudo. Match the returned PCI bus ID to BDF. A missing command or a driver/library error is distinct from an absent GPU; this query is not suitable for a Nouveau-only binding.
