Ethernet & networking

Intel I217-LM

An Intel PCH LAN generation handled by e1000e. Treat it as a platform-integrated network function; a generic PCI adapter description does not identify the motherboard wiring or management configuration.

Overview & identity

The source constant names 153a as PCH LPT I217-LM. This LM identity is separate from nearby I217-V and other PCH LAN device IDs.

Curated identifiers
pci 8086:153a

A numeric match establishes a candidate family within the reviewed evidence. Marketing names, board variants, subsystem conditions and successful operation remain separate questions.

Driver & binding

The ID is in e1000e rather than igb or igc. Platform power and PHY handling share the e1000e path, while only the observed binding tells which running driver owns the function.

  • e1000e — kernel driver/module candidate

Detected, bound, operational: learn the difference

Read-only diagnostics

Run one displayed command at a time. Replace uppercase placeholders with the affected device, interface or module from your own output. Commands are never executed here. Read-only output can still contain private identifiers.

Check the PCI function and bound driver

lspci -nnk -s BDF

Replace BDF with the domain:bus:device.function address. Look for [8086:153a] and Kernel driver in use. e1000e in Kernel modules is only a candidate, not proof of binding.

Identify the network interface driver

ethtool -i INTERFACE

Replace INTERFACE with the real interface name. Driver and bus-info connect this interface to its device. A displayed firmware-version is adapter information; it does not prove a file was loaded. Candidate: e1000e.

Compare supported modes with the current link

ethtool INTERFACE

Supported/advertised link modes describe capability or negotiation offers. Speed, Duplex and Link detected describe the current link, not measured throughput. An unsupported query is a limitation of the interface/driver.

Separate PCIe transport from Ethernet speed

sudo lspci -vv -s BDF

Elevated access may be needed. Root can expose the full PCI configuration. If PCIe capabilities exist, compare LnkCap with LnkSta: maximum and negotiated PCIe speed/width are different from Ethernet speed. Legacy PCI or virtual functions may omit these fields.

Limitations & related issues

Suspend/resume or wake-on-LAN observations need the motherboard and firmware context. The LM suffix is not proof that a management service is active or reachable.
