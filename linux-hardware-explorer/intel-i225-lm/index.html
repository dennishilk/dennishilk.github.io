Intel I225-LM

A newer Intel copper controller generation matched by igc. The verified identifier distinguishes I225-LM from I225-V, I226 and blank-NVM entries in the same driver family.

Overview & identity

15f2 is named I225_LM by the upstream header and appears in the igc PCI table. Its revision and OEM subsystem remain necessary for a board-specific investigation.

Curated identifiers
pci 8086:15f2

A numeric match establishes a candidate family within the reviewed evidence. Marketing names, board variants, subsystem conditions and successful operation remain separate questions.

Driver & binding

The expected upstream kernel candidate is igc, not e1000e simply because the vendor is Intel. Availability in a source snapshot is different from presence in an older distribution kernel.

  • igc — kernel driver/module candidate

Detected, bound, operational: learn the difference

Read-only diagnostics

Run one displayed command at a time. Replace uppercase placeholders with the affected device, interface or module from your own output. Commands are never executed here. Read-only output can still contain private identifiers.

Check the PCI function and bound driver

lspci -nnk -s BDF

Replace BDF with the domain:bus:device.function address. Look for [8086:15f2] and Kernel driver in use. igc in Kernel modules is only a candidate, not proof of binding.

Identify the network interface driver

ethtool -i INTERFACE

Replace INTERFACE with the real interface name. Driver and bus-info connect this interface to its device. A displayed firmware-version is adapter information; it does not prove a file was loaded. Candidate: igc.

Compare supported modes with the current link

ethtool INTERFACE

Supported/advertised link modes describe capability or negotiation offers. Speed, Duplex and Link detected describe the current link, not measured throughput. An unsupported query is a limitation of the interface/driver.

Separate PCIe transport from Ethernet speed

sudo lspci -vv -s BDF

Elevated access may be needed. Root can expose the full PCI configuration. If PCIe capabilities exist, compare LnkCap with LnkSta: maximum and negotiated PCIe speed/width are different from Ethernet speed. Legacy PCI or virtual functions may omit these fields.

Limitations & related issues

Link-mode capability is not the rate actually negotiated with the switch. This profile does not label all I225 revisions as faulty or recommend a universal firmware or EEE change.

These guides are linked for relevant observations, not as known defects of every device in this family.
