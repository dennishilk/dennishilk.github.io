Overview & identity

The curated PCI identity is 14c3:7925. It is a checked family candidate and does not name a unique marketed adapter.

Curated identifiers
pci 14c3:7925

A numeric match establishes a candidate family within the reviewed evidence. Marketing names, board variants, subsystem conditions and successful operation remain separate questions.

Driver & binding

mt7925e has the 7925 entry and associates it with MT7925 firmware data. The same transport file contains newer distinct families, so inspect the ID before assigning firmware.

  • mt7925e — kernel driver/module candidate

Read-only diagnostics

Run one displayed command at a time. Replace uppercase placeholders with the affected device, interface or module from your own output. Commands are never executed here. Read-only output can still contain private identifiers.

Read the selected PCI function

lspci -nnk -s BDF

Replace BDF with the address from your report. Compare Kernel driver in use with Kernel modules; only the former records binding. This ordinary query normally needs no root privileges.

Read firmware metadata

modinfo -F firmware MODULE

Replace MODULE with mt7925e or the actual candidate module in your report. Metadata lists declared filenames; it does not prove a file was loaded. This query needs no root privileges.

Read existing Wi-Fi association

iw dev INTERFACE link

Replace INTERFACE with the wireless interface from iw dev. Association and rate are observations, not a throughput or firmware test. This query normally needs no root privileges.

Limitations & related issues
