2. Allgemeines zur Datenverarbeitung

Diese Website dient ausschließlich der Präsentation von Open-Source-Projekten. Es werden keine personenbezogenen Daten durch mich erhoben oder gespeichert.

Technische Zugriffsdaten können jedoch durch den Hosting-Anbieter GitHub Pages verarbeitet werden.

3. Server- und Zugriffsdaten

GitHub Pages erhebt automatisch technische Daten, z. B.:

Diese Daten werden ausschließlich für den technischen Betrieb benötigt und nicht von mir ausgewertet.
