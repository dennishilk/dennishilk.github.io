2. General information about data processing

dennishilk.com is a personal website used primarily to present open-source projects and observational dashboards. Accessing a website necessarily generates technical access data. This privacy policy describes which data may be processed when providing this website and in connection with the Site Traffic Observer.

No advertising trackers, Google Analytics or marketing cookies are used. The production website is self-hosted; GitHub is linked only as an external platform for project repositories and source code.

3. Website delivery via worldnode / nginx

The production website dennishilk.com is hosted on the self-operated server worldnode and delivered through nginx. nginx writes access data to access logs when pages, files or other website resources are requested.

Where necessary, this technical data is processed to deliver the website, maintain technical operation, troubleshoot problems, provide security and enable traceable observation of website traffic.

4. Server and access data / nginx access logs

The nginx access logs may in particular process the following technical access data when it occurs during a website request:

  • IP address of the requesting connection
  • date and time of access
  • requested page, file or resource
  • HTTP method and response status
  • amount of data transferred
  • referrer, if transmitted by the browser or client
  • user agent, including browser, operating-system, bot or crawler indicators
  • request patterns derived from access data
  • country-level geographic classification for aggregated observations

This raw data is distinct from later aggregated observational data and from the data shown publicly in dashboards. Raw technical access-log data is not displayed as raw visitor IP addresses in the public Traffic Dashboard.

5. Site Traffic Observer

The Site Traffic Observer evaluates nginx traffic and access-log data to present website traffic observationally and in aggregated form. The public dashboard is available at /traffic.html and itself identifies the source as worldnode / nginx access logs, human classification through request-pattern and user-agent heuristics, no disclosure of raw visitor IP addresses, and storage as aggregated observational data.

The Observer distinguishes and aggregates, in particular, human requests, pageviews, estimated unique visitors, bots, crawlers and scanners, request and usage patterns, requested pages, referrers and geographic information at country level.

Classification as human, bot, crawler or scanner is heuristic and based on request patterns and user-agent information. Geographic presentation is limited to country level. The dashboard displays aggregated observations such as top countries, frequently observed pages, crawler types and referrers; raw visitor IP addresses are not publicly disclosed there.

The Novel Reader Signal is also derived from first-party nginx access logs. Novel Pageviews and Chapter Opens are only qualifying HTTP page requests; a Chapter Open does not prove that a chapter was read or completed. Reading duration and reading progress are not measured. EST. READERS · 24H is an aggregated estimate for a rolling 24-hour window. Source addresses may be processed temporarily in memory solely for aggregation; no persistent reader identity or individual reading history is created. No cookies, accounts, browser fingerprinting or third-party analytics are added for this purpose. Raw IP addresses and individual request records are not published. Per-chapter and all-time values are aggregated statistics only; the novel reader all-time values begin at the date published in the dataset as all_time.since.

6. Purposes of processing

  • technical delivery of the website and requested content
  • operation, maintenance, error analysis and stability of the website
  • detection of unusual access patterns, bots, crawlers, scanners and technical faults
  • aggregated observation of pageviews, estimated visitor numbers, referrers and requested pages
  • transparent publication of non-raw, aggregated traffic signals in the public dashboard

7. Legal basis and legitimate interests

Where technical access data is necessary to provide the website, processing is based on Art. 6(1)(f) GDPR. The legitimate interest is the secure, stable and functional operation of the website.

Where access data is evaluated internally for security, error analysis and traffic-observation purposes or combined into aggregated observational data, processing is likewise based on Art. 6(1)(f) GDPR. The legitimate interest lies in protecting the service, detecting technical or abusive access patterns and presenting website traffic transparently and with data minimisation, without publicly displaying raw visitor IP addresses.

8. Storage, deletion and aggregated observational data

Technical access logs and data derived from them are not retained longer than necessary for operation, security, error analysis and the observational purposes described above. Under the current server configuration, nginx log files are rotated daily and up to 14 rotated log files are retained; older rotated log files are removed as part of log rotation.

The Site Traffic Observer works with aggregated observational data. Such data may be retained for longer where it does not represent public raw data from individual visitor requests, but instead consists of aggregated signals such as counts, ratios, country aggregation, referrer statistics or page statistics.

The legal basis is Art. 6(1)(f) GDPR; for pre-contractual or contractual enquiries, Art. 6(1)(b) GDPR may additionally apply.
