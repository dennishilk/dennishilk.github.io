Original German and English vocabulary: common words, generic names, animals, nature, seasons, months, places, hobbies and technology. Fixed adjective + noun patterns expand that vocabulary. No breach data, password dumps or remote lists.
Optional case variants, two defined whole-word leetspeak forms, numerical suffix widths 0–4 and an inclusive year range from 1900 to 2099. Duplicate word variants are removed before counting. Year and suffix phases can repeat the same value; every indexed range remains distinct.
Generated bases are ASCII and at most 20 characters; four-digit additions stay within the 24-character candidate limit. Accented input is hashed exactly but is not silently converted into ASCII.


Privacy, long runs & what the result means
UNDERSTAND THE EXPERIMENT
This is an offline attack on a deliberately fast, unsalted SHA-256 teaching hash. It is not an attack on a website, account or password manager. SHA-256 alone is unsuitable for modern password storage.
Salts and modern hashing
A unique salt separates each stored password hash. Argon2id deliberately adds work and memory cost. Our fast SHA-256 figures do not predict the cost of cracking properly configured Argon2id hashes.
An exhausted or stopped search is no proof of password safety. Online rate limits, MFA and proper salted password hashing change real-world attacks.
LONG RUNS & PRACTICAL LIMITS
No automatic 5-, 10- or 30-second cutoff. The experiment runs until a verified match, exhaustion, an engine error, or your Stop command. Pause retains the open session.
Sustained load uses battery and increases device temperature. Start with low intensity on laptops and phones. This page pauses a running search when hidden; a closed or suspended tab cannot reliably compute.
Privacy and local cleanup
The lab has no password network endpoint and stores neither the password nor its hash in URLs or browser storage. Reset, completion and page departure terminate workers and clear practical buffers. Reveal is explicit and local. Browser extensions or compromised browser software can still observe inputs; JavaScript strings cannot be securely overwritten.
