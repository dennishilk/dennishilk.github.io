# Third-Party Notices

The Commodore 64 Programming Lab contains no third-party runtime, ROM image,
character ROM, game, commercial sprite, copied manual page, CDN font, or
emulator binary.

The interpreter, worker, browser teaching renderer, lesson text, example
programs, and 63-byte STAR RUNNER rocket sprite are original project code and
content.

The display uses the visitor operating system's generic monospace font through
the browser canvas API. No font file is distributed.

Historical names such as Commodore 64, BASIC V2, VIC-II, SID, and PETSCII are
used solely to identify and explain the historic platform. This unofficial
educational recreation is not affiliated with or endorsed by Commodore.

External historical references are linked, not copied. Their respective sites
and documents remain under their own terms.
