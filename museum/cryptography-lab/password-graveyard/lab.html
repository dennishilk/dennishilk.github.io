THE PASSWORD GRAVEYARD

1. PLAINTEXT GRAVE

alice | sunshine
bob   | dragon
carol | museum123
Stored text is immediately readable.

2–4. HASHES, SALTS, PRECOMPUTATION

A salt is not secret. It stops identical passwords producing identical stored values and prevents universal reuse of a tiny precomputed lookup shelf.

5. FAST VS SLOW

Illustrative normalized work only: general hashes such as SHA-256 are not “broken”; their speed makes them unsuitable by themselves for password storage.

6. REUSE DOMINO

MAIL · SHOP · FORUM each use the same fictional secret.

7. MODERN VAULT

password + unique random salt + memory/time-cost password hashing → stored verifier

Use a password manager for unique passwords; MFA and passkeys can add protection. Parameters must fit the deployment and evolve.
