Museum disclosure
The Midnight Relay is a fictional browser simulation inspired by dial-up bulletin board systems of the late 1980s and early 1990s. It does not connect to a telephone network or public BBS. Other callers are simulated, and visitor-created content remains in this browser.
No backend, public messaging, real Sysop, telephone connection, or remote content is used. THE OPERATOR and every other caller are scripted fictional characters. Transfers are educational protocol simulations, not wire-compatible implementations; nightly network mail is deterministic store-and-forward theatre with no network request.


Exhibit context and operating notes
About the system
Four simulated nodes · ANSI and ASCII · 300–14,400 bit/s · browser-local persistence. Use modem commands or Call the Board, then log on as GUEST or NEW. Type ? at any prompt.
Keyboard controls while the terminal is focused: Ctrl-S pause, Ctrl-Q resume, Ctrl-C abort output, Ctrl-K controls, Ctrl-T call statistics, Ctrl-U online users, and Ctrl-P one-line node message. Escape closes overlays. No browser shortcut is intercepted outside the terminal input.
The negotiation reuses the Modem Lab’s local public-domain historical recording, modem-handshake.ogg, sourced there from Wikimedia Commons. Dial tone, DTMF, and ringback are generated locally; visible stage labels are an educational approximation rather than a chirp-by-chirp protocol trace.
Door launches show a museum representation of caller-data “drop files” such as DOOR.SYS. Real BBS packages wrote caller data for external programs; this representation does not claim binary compatibility.
Local exhibit passwords are only for this fictional museum account. Never reuse a real password. A digest—not the password—is stored in this browser.
