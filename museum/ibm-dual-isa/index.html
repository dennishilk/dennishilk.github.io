        What exactly is executed?
        IBM Z: LGHI, AGR, CGR, BRC, STG, LG. Arm A64: MOVZ, ADD (register), CMP (register), B.EQ, STR and LDR (64-bit, base register). Only the forms in these listings are supported. 64-bit integer wrapping, IBM condition codes and Arm CMP flags are modeled. IBM Z data uses big-endian order; the Arm example uses little-endian order. Arm X4 starts at byte address 128.
        The PC is a zero-based source-listing index, not a byte address. Labels resolve to listing indices. Reaching the end stops this teaching harness; no invented HALT instruction is used. There is no OS, privilege, exception, virtual memory or cycle-accurate pipeline model.
