    Transparency

    The browser reduces commands before submission, and the collector independently normalizes them again. Arguments that could contain personal text, paths, addresses, or secrets are discarded. The collector does not intentionally persist request headers; ordinary nginx or service logs may contain request metadata unless operators disable them as described in the deployment guide.
