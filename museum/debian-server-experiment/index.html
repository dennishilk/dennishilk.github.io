museum@debian:~$ Try a Debian Server

PLANNED

A small Debian system will be made available for free exploration.

You will enter an unfamiliar Linux environment without a tutorial and decide independently what to inspect, test, create, modify or remove.

THE CONCEPT

Free exploration, within clear boundaries

The planned experience is an unguided, controlled Debian-like environment running entirely in the browser. Changes will remain consistent during a session, allowing visitors to explore the consequences of their own choices.

It will be a simulation—not a real machine, remote server, virtual machine or emulator. Responses will follow defined system behavior rather than being generated by AI, and the experience will not be presented as a hacking game.

PRIVACY PLAN

Anonymous by design

  • No account, name or personal identification will be required.
  • No IP address will be shown, and no real server will be accessed.
  • Editor contents and freely entered personal text should not be stored in aggregate analytics.
  • Only anonymous, normalized session statistics are planned; analytics do not exist yet.

A DIFFERENT KIND OF LINUX EXPERIENCE

Alongside Linux Terminal Academy

Linux Terminal Academy teaches Linux through guided labs. Try a Debian Server will instead study free exploration without instructions. The projects complement each other, but serve different purposes.
