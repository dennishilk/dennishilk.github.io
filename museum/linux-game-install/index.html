Browser-only educational simulation

Everything in the terminal is controlled virtual state in this page. Commands never execute on your computer: there is no real sudo access, shell, filesystem access, package installation, Debian mirror request, telemetry, or server-side backend.

Why package managers matter

Repositories

Linux distributions commonly provide software through curated package repositories. A package manager can discover what is available from a configured catalog.

Dependencies

Debian’s apt workflow resolves the packages needed by a program, rather than asking visitors to locate every component manually.

Free software, specific terms

Free/open-source software can be redistributed under its own licenses. Availability in Debian alone is not a blanket permission to repackage any software or media.

Teaching example: OpenTTD

OpenTTD is used here because it is free/open-source software and has free replacement base-set projects: OpenGFX/OpenGFX2 graphics, OpenSFX sound effects, and OpenMSX music. This exhibit does not include original Transport Tycoon Deluxe graphics, sound, music, MicroProse assets, ROMs, or abandonware.

The lab represents package names and an apt workflow locally. A browser-compatible OpenTTD runtime has not been bundled because no official/reproducible static-hosting build and complete redistribution compliance package was verified during this implementation. The final screen says so plainly rather than imitating a game binary.
