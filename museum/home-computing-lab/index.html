One personal computing environment — spanning more than 25 years of computer history.

This planned exhibit documents real systems that are still connected and used. Rather than recreating history only in software, it follows original hardware, legacy applications, modern Linux systems and current server infrastructure as they coexist through carefully designed compatibility layers.

Why this is a museum exhibit

The focus is not a collection of isolated machines. Each system is a layer in a longer story: hardware supports operating systems; operating systems run applications; applications use protocols; protocols cross networks; and servers make services possible. The lab makes those relationships visible.

Old and modern computers do not have to be kept apart. They can communicate when their boundaries are understood and compatibility is designed with care.
