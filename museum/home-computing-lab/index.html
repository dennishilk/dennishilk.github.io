Why this is a museum exhibit

This is the real infrastructure behind dennishilk.com and the Computer Museum, documented as a connected environment rather than a generic homelab.

Each system is a layer in a longer story: hardware supports operating systems; operating systems run applications; applications use protocols; protocols cross networks; and servers make services possible. The lab makes those relationships visible.

Old and modern computers do not have to be kept apart. They can communicate when their boundaries are understood and compatibility is designed with care.
