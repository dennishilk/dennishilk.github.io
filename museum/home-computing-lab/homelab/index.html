Small scale, real principles

A homelab is a private environment for running and learning from real services. This one includes a 19-inch rack, an HP MicroServer Gen10, Linux systems, network equipment, storage and services. It is not a data center, and it does not need to be one: its value is that the same ideas—separation of roles, dependable services, backups, monitoring and careful change—can be explored at personal scale.

Always on

A desktop may sleep or be repurposed. A server is arranged around services that should remain available, such as file sharing and compatibility services.

Contained services

Docker packages an application and its dependencies into containers. This makes it easier to run distinct services without treating every experiment as the whole machine.

Practice environment

Linux, network services and Samba file sharing create a place to test administration skills and understand what sits behind a familiar desktop.

Infrastructure with a human scale

The rack connects storage, services and legacy compatibility work to the rest of the home network. Future photographs will document the actual equipment without inventing a rack diagram or claiming unrecorded device positions.
