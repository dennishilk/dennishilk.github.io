Hardware

Workstations, the rack, storage, network equipment and remote servers make the physical foundation visible.

Software & protocols

Operating systems run applications; Samba, OSCAR, HTTPS and other protocols define how those applications communicate.

People & services

Infrastructure exists to support people: learning, preserving software, publishing work and maintaining useful connections.

A system is rarely one computer

Modern computing is a network of hardware, operating systems, applications, protocols, services, storage and people. The The Author's Computing Lab uses one real environment to show how those layers can span decades without losing their individual histories.
