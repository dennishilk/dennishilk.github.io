FIELD NOTE #005 · DOCUMENTED 2026

THE IDE CABLE

A storage upgrade that Windows 98 recognized as SCSI hardware led back to one IDE cable.

A storage upgrade in a Windows 98 computer produced an unexpected result.

Although the drive was connected through an IDE cable, Windows reported the storage hardware as SCSI.

Objective

Upgrade the computer’s storage while keeping the original Windows 98 system working.

The Unexpected Result

After the upgrade, Windows 98 identified the storage system as SCSI hardware.

The system was working, but the description did not appear to match the physical IDE connection.

Device Manager

System Information

Result

The storage upgrade remained operational. The familiar IDE cable and the SCSI label were both accurate parts of the same working configuration.

Lesson Learned

The name shown by an operating system does not always describe the physical connection in the way expected at first glance.

Evidence

The photographs document the installed hardware and the storage information reported by the original Windows 98 system.
