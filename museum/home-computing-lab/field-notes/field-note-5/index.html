FIELD NOTE #005 · DOCUMENTED 2026

THE IDE CABLE

A planned conversion from SCSI to IDE required only a small amount of technical work. Finding the required cable took considerably longer.

Objective

The Windows 98 retro PC used an Adaptec 2940W / 2940UW SCSI controller together with SCSI drives. The setup was functioning normally; it was not being removed because it was broken or unreliable.

The objective was practical: remove the SCSI controller and drives, install IDE drives instead, and free the occupied PCI slot for my preferred sound card. IDE was not being chosen as technically superior, but as a simpler configuration for this particular retro PC.

Expected Work

The technical conversion appeared straightforward.

Remove the SCSI hardware.

Connect the IDE drives.

Install the sound card.

Boot Windows 98.

The expected workshop time was only a few minutes.

Unexpected Obstacle

The hardware conversion itself was not the problem.

The required IDE ribbon cable was.

I knew that old IDE cables had to be stored somewhere among the accumulated computer parts. The first likely place was the attic.

The Search

Up to the attic.

SCSI cable.

Another box.

Another SCSI cable.

Back downstairs.

Check the wall cupboard.

More old parts.

Still no IDE cable.

Back to the attic.

More SCSI.

Again downstairs.

Think again.

Again upstairs.

Still SCSI.

Over approximately five trips between the attic, the wall cupboard and the work area, I apparently owned many SCSI cables at exactly the moment when one IDE cable was needed.

Eventually, after several search rounds, one sufficiently long IDE ribbon cable was found. That single cable was long enough to connect the hard disk, CD drive and CD writer.

The Conversion

Once the IDE cable had been found, the actual conversion was straightforward.

The Adaptec SCSI controller was removed. The SCSI storage setup was replaced with IDE drives, and the newly available PCI slot was used for my preferred sound card.

Result

Windows 98 started normally after the conversion. It remained the same Pentium III retro PC with 128 MB RAM shown in the evidence.

IDE storage installed. SCSI controller removed. PCI slot freed. Preferred sound card installed. Windows 98 booted successfully.

Lesson Learned

The actual conversion took only a few minutes.

Finding one ordinary IDE ribbon cable took much longer.

A workshop can contain twenty examples of the wrong cable and still hide the only one currently needed.

One apparently owns twenty SCSI cables. Naturally, the day one needs a cable, it must be IDE.
