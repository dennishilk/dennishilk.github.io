A workstation, not just a PC

Cthulhu is the modern working end of this environment: an Arch Linux computer used for daily computing, software development, website and Computer Museum work, World Observer work, and Linux gaming. Its AMD Ryzen 7 5800X3D processor, Radeon RX 9060 XT with 16 GB of graphics memory, 32 GB of RAM, and 3440 × 1440 ultrawide display describe a machine designed to do many kinds of work without changing its role.

Arch Linux supplies the operating system; the sway window manager arranges the desktop around keyboard-driven workflows. Package management keeps software installable and updatable as a coordinated system rather than as a shelf of physical boxes.

1998 PC

Usually built around one processor core, modest memory, local installation media and a desktop designed for a single machine. Networking was valuable, but not assumed to be part of every task.

2026 workstation

Many processor cores, a capable GPU, abundant memory and persistent networking let one computer be a creative workstation, development platform, game machine and client of other services at once.

Architecture changed more than speed

Multi-core processors allow separate tasks to make progress together. GPUs have become programmable, high-throughput companions to the processor. Linux offers many desktop environments and window managers, so the interface can be adapted to a workflow. Modern tools also assume fast networks: code, documentation, services and collaborators may be elsewhere even when the work is local.
