A shared environment, not a flat one

A LAN (local area network) connects devices in one place. A router moves traffic between networks; a firewall applies rules about which traffic is allowed. Devices use IP addresses as network labels, while DNS turns human-readable names into addresses. This exhibit intentionally uses an abstract diagram rather than publishing an internal layout.

Samba is a file-sharing service that lets different operating systems exchange files using a familiar network-share model. In this environment, services help modern and legacy systems cooperate without pretending they are identical.

Compatibility includes protection

Legacy operating systems should not simply be opened to the modern internet. Segmentation and controlled services reduce unnecessary exposure. The educational lesson is not a configuration recipe; it is that networking is both connection and boundary-setting.
