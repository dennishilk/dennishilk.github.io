Original hardware, present-day context

This is a real Windows 98 computer, not an emulator. Its CRT-era workstation style, classic peripherals, locally installed software, games, Winamp, ICQ 2000b and working Iomega Zip 100 MB drive make it a practical record of late-1990s and early-2000s desktop computing.

The point is not nostalgia alone. Each physical detail explains a constraint: applications arrived on media, files lived on the machine, and network access was slower and less universal. The desktop was a place where programs and documents were visibly owned, installed and managed.

Local software

Programs were normally installed from disks or discs. Their interface and data remained close to the user instead of being primarily account- and cloud-centred.

Physical media

Removable media made transfer, backup and distribution tangible. Capacity limits shaped which files were worth carrying.

Controlled connection

The system can participate in a modern network, but legacy operating systems should be protected rather than exposed directly to today’s internet.
