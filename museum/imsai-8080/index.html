Keyboard & front-panel guide
Use Tab and Space/Enter on switches and controls. Within the workbench, F7 steps and F8 runs/stops. EXAMINE copies the 16 input bits to the address pointer. DEPOSIT writes the lower 8 bits there. NEXT advances by one. RUN starts at that pointer. RESET resets registers and stops, preserving RAM.

FIELD NOTES / CONTEXT & LIMITS
A machine from 1975. A story from 1983.
The IMSAI 8080 was introduced in 1975, closely following the MITS Altair 8800. Both helped make the expandable microcomputer a practical proposition for enthusiasts. The front-panel switches exposed memory and machine instructions directly; a keyboard, terminal and disk system were additional equipment, not software hidden inside the panel.
Intel’s 8080 is an 8-bit processor with a 16-bit address space. Here you can inspect its seven 8-bit registers, flags, stack and 64 KiB memory. The famous blue terminal exchanges belong to the fictional world of WarGames (1983). IMSAI’s own production history documents supplying the computer, disk drives, keyboard and monitor for the film.
What this emulator does
The original interpreter implements the documented Intel 8080 instruction set, flag arithmetic, stack operations, 16-bit wrapping, interrupt enable delay and nominal instruction cycle counts. Single-step is one whole instruction. The LEDs sample the inspected address, memory byte and CPU state; they are not an electrical bus trace.
This is not a cycle-exact IMSAI system emulator. The serial ports are museum conventions. There is no S-100 bus timing, original UART, floppy controller, ROM, CP/M, IMDOS, peripheral interrupt source or audio. Browser timing is intentionally throttled; the counter demo stops after a bounded run. No external CPU diagnostic suite is claimed as passed.

Learning from the fiction
School records teach reversible edits; reservations demonstrate state and availability. Joshua combines a curated chess study, a full Tic-Tac-Toe game-tree search and an explicitly authored escalation model. Its conclusion is a narrative lesson, not a real military forecast. All people, telephone numbers, destinations and strategic sectors in these applications are invented.
Independent educational reconstruction. No film frames, film audio, proprietary binaries or original software are distributed. Brief film references and names identify the cultural context; this exhibit is not affiliated with Intel, IMSAI or the film’s rights holders.
