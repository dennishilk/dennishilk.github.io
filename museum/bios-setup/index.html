About this exhibit

The BIOS Setup Utility is an original educational environment inspired by PC firmware interfaces from the late 1980s through the late 1990s. It is not a motherboard BIOS, UEFI implementation, extracted firmware, ROM image or exact recreation of a vendor product.

What this exhibit lets you explore

  • Navigate an original keyboard-first BIOS-style interface.
  • Change virtual boot devices, memory and hardware options.
  • Save a browser-local virtual CMOS configuration.
  • Restore safe optimized defaults without affecting the real computer.

Safety boundary

The exhibit runs entirely inside the browser. It cannot access firmware, hardware settings, the operating system, real disks or files on the visitor’s computer. All configuration data belongs only to this educational simulation.

Recreation notice

This exhibit combines historically familiar BIOS concepts into one original museum interface. It is inspired by an era of computing rather than one specific motherboard or vendor utility. No proprietary firmware, trademarks, ROM images or original BIOS software are distributed.
