Scenario guide & terminal commands
Commands: help, status, diagnose, isolate, reboot, restore power, restore communications, restore fences, restore doors, ls, pwd, cd PATH, cat PATH, open PATH, clear. The buttons perform the same actions. After step 6, open Physical.Plant → Physical.Security → Visitor.Center → door.control in the workstation and use its restore button. “access security” hides a small surprise; “please” is useful afterwards.
The film’s dramatic recovery is not a real operating procedure. Here every control changes only temporary page state; a reload or scenario reset clears it. No real security system is controlled.

FIELD NOTES / 1990s VISUAL COMPUTING
The technology was real.
The park is fiction. The information landscape wasn’t.


01 / SGI & IRIX
A different class of desktop
Silicon Graphics built graphics workstations for demanding visual and technical work. IRIX was its UNIX operating system. SGI’s own software archive offers fsn for IRIX 4.0.1 and later: this landscape belongs to real workstation history.


02 / fsn
Directories became places
Pronounced “fusion”, fsn explored navigating information as a landscape. Directories stood on pedestals connected by wires; files became boxes. Height represented size and color represented age. SGI explicitly described it as an experiment, not a complete file manager.


03 / CINEMA
Recognition in the control room
In Jurassic Park (1993), Dennis Nedry’s sabotage compromises the park. Later, Lex Murphy recognizes the UNIX workstation and navigates the files to help secure the visitor center. That memorable 3D view was based on real fsn. Recognizing UNIX alone would not explain a custom park-control application.


04 / THIS EXHIBIT
What you are actually operating
Original browser code, a fictional park tree and a deliberately simplified recovery model. The case is SGI-inspired rather than an exact model replica; the desktop mixes period references. It is not an IRIX emulator, original fsn or a recovered film application. Size uses a compressed scale here, and file ages are invented.
