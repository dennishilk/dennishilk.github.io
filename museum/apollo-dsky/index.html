  • VERB / NOUN style interaction
  • Keypad controls

Historical context

The Apollo Guidance Computer used the DSKY as an astronaut-facing interface for entering commands and reading key guidance data.

Recreation notice

This educational recreation will use original HTML, CSS and SVG only. It is not a flight-certified system or exact hardware emulator.

These exhibits are independently created educational simulations. No proprietary ROM images, operating-system files or original software are distributed.
