About this exhibit

DSKY means Display and Keyboard. The DSKY was the astronaut-facing interface to the Apollo Guidance Computer; this exhibit recreates selected interface ideas, not the larger guidance computer itself.

What you will try

  • Enter two-digit VERB codes for actions and NOUN codes for the data or object involved.
  • Watch compact PROG, VERB, NOUN and register displays respond to educational simulated commands.
  • See how annunciator lamps communicate activity, operator errors and a controlled alarm demonstration.
  • Learn why limited computing and display resources encouraged terse, disciplined interaction.

Educational context

Astronauts used numeric codes because the interface had only a small keypad, lamps and compact numeric registers. VERB described what to do; NOUN identified the data to display or act on; ENTR confirmed each code.

Recreation notice

This is an original educational recreation using HTML, CSS and JavaScript. It is historically inspired, browser-local and deterministic, but it is not an AGC emulator, not original Apollo software, not a complete mission simulation and not a flight system.

No ROMs, original AGC programs, proprietary assets, backend services or external runtime dependencies are used.
