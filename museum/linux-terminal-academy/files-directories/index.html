museum@linux:~$ FILES & DIRECTORIES LAB

MAKE A CHANGE—THEN UNDERSTAND IT

This planned lab turns commands into visible changes in one fictional virtual filesystem state. Mistakes are part of learning, and every exercise will be reversible.

WHAT YOU WILL LEARN

  • Create places and files with mkdir and touch.
  • Copy, rename, and remove with cp, mv, and rm.
  • Read file content with cat, less, head, and tail.

MISSION PREVIEW

CREATE A DIRECTORY
CREATE A FILE
COPY · RENAME · DELETE

GOOD.
YOU DELETED IT.

NOW RECOVER IT.

FUTURE INTERACTION

Commands will modify only the lab’s fictional filesystem; visitors will see each consequence and can reset the virtual machine.

SAFETY / BROWSER-ONLY

This lab is planned information only. It does not include an interactive terminal yet, and it will never run real shell commands or access your files, processes, services, or operating system.
