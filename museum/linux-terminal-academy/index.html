LEARN LINUX ONLINE IN A SAFE BROWSER LAB

The Linux Terminal Academy teaches practical command-line habits through a fictional, resettable Linux environment. Work through terminal basics, filesystem navigation, permissions, process control, shell pipelines, administration and recovery without installing Linux or connecting to a real shell.

YOUR COMPUTER STAYS UNTOUCHED.

Every exercise runs only in a fictional browser environment. No real shell, files, processes, services, network, or sudo access.

GRADUATION CHALLENGE · OPTIONAL CERTIFICATE

Complete the final recovery challenge in Lab 08 and you may earn a printable Linux Terminal Academy certificate. Practice freely, use hints while learning, and try as many times as you need.

  • Hints in Labs 01–07 are fine.
  • Mistakes and experimentation are fine.
  • One hint-free Lab 08 attempt earns the certificate.

YOU DON'T NEED TO LEARN 1,071 COMMANDS

A real Debian server behind this museum currently exposes 1,071 unique terminal commands. You do not need to memorize them.

Linux is about learning how to navigate, inspect, combine small tools, read manuals, and troubleshoot. These eight labs teach exactly that.
