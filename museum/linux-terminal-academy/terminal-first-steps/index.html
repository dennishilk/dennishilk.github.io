museum@linux:~$ TERMINAL FIRST STEPS

MEET THE COMMAND LINE

The terminal is simply another interface to the operating system. This first planned lab begins with orientation, not memorization; no prior Linux knowledge is required.

WHAT YOU WILL LEARN

  • Use pwd, whoami, uname, and date to ask basic questions.
  • List and change locations with ls and cd; use clear when the screen needs a reset.
  • Understand that help and man are ways to look up a command, not magic words to memorize.

FUTURE INTERACTION

SAFETY / BROWSER-ONLY

This lab is planned information only. It does not include an interactive terminal yet, and it will never run real shell commands or access your files, processes, services, or operating system.
