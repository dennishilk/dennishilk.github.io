About this exhibit

The DOS Setup Utility is an original Computer Museum experience inspired by late-1980s and 1990s game and application setup programs. It is not an installer, not a game setup executable, not extracted DOS software and not an emulator.

What this exhibit lets you explore

  • Navigate a keyboard-first, step-by-step DOS setup wizard.
  • Configure digital audio and music separately, including ports, IRQs and DMA channels where appropriate.
  • Play original browser-generated test sounds and synthesized music that vary with the selected virtual devices before confirming the choices.
  • See how hardware choices influence which configuration steps appear as the setup flow adapts to the chosen virtual hardware.
  • Try educational joystick/input indicators with simulated keyboard or touch controls.
  • Save a private virtual SETUP.CFG-style configuration to localStorage without touching the real computer.

Safety boundary

Everything runs in the browser. No DOS, VM, emulator, proprietary installer, original game data, real hardware setting or operating-system file is used. Virtual files such as SETUP.CFG and SOUND.CFG exist only as browser-local museum data.

Recreation notice

This exhibit combines familiar setup concepts from the era into one original educational interface. Configuration choices influence the simulated setup experience in historically inspired ways, allowing visitors to explore how DOS-era software adapted to different hardware configurations without recreating one specific commercial product.
