A photo is too large for a website, a screenshot needs a transparent background, or a WebP image has to be sent as a JPG. A useful image converter should produce the format you selected and let you control dimensions and quality.

My free image converter converts and resizes images directly in your browser. The selected image files are processed on your device instead of being uploaded to a server. This guide explains how to choose a format and check the result.

What does “without uploading” mean?

Your browser opens the file you select, redraws the image and creates a new file for download. My converter uses the browser's own image APIs. You do not need an account or a separate image-editing application.

This is particularly useful for private photos or screenshots containing personal information: conversion does not require you to leave another copy with a service. You decide whether and where to share the finished file.

Opening the website still downloads HTML, scripts and other page resources. “No image upload” describes how your selected images are handled; it does not mean that visiting the website creates no connection to a web server. The privacy policy explains the hosting side.

JPG, PNG or WebP: Which should you choose?

Format Useful for What to check
JPG / JPEG Photos and recipients that require JPG Lossy compression; no transparent background
PNG Screenshots, text-heavy images and transparent graphics Lossless raster export; photos may produce large files
WebP Website images and applications that support it Can preserve transparency; compare quality and file size

JPG and JPEG refer to the same image format. Changing a filename extension does not convert the file.

For a website photo, WebP is worth comparing with your original. For a screenshot with small text, inspect the edges carefully. PNG may be a better fit even if it produces a larger file. If the recipient specifically needs JPG, meeting that requirement matters more than producing the smallest possible download.

The converter accepts JPG/JPEG, PNG and WebP. AVIF works as an input when your browser can decode the file. Output is JPG/JPEG, PNG or WebP, depending on the formats your browser can encode. AVIF export is not included.

Convert an image in three steps

  1. Open the image converter and select one or more image files. You can also drag them into the file area.
  2. Choose an output format. Adjust quality and maximum width or height if needed.
  3. Start local conversion, inspect the result and download the files.

Keep the originals until you have checked the export. Conversion creates a new file; it cannot restore detail that was already missing from the source.

To convert JPG to WebP, choose WebP as the output. To convert WebP to JPG, choose JPG/JPEG. If a transparent WebP background needs to stay transparent, PNG is usually the more appropriate alternative to JPG.

You can select several images and process them sequentially. For a large batch, try a representative file first before applying the same settings to everything.

Resize images before chasing smaller files

Changing the format is only part of reducing an image's size. A 6,000 × 4,000 image contains 24 million pixels. Resizing the same composition to 1,500 × 1,000 leaves 1.5 million pixels: one sixteenth of the original pixel count.

That is a dimensions example, not a measured file-size saving. The final byte size also depends on the subject, format and encoder.

Choose dimensions for the intended use. A small thumbnail has different needs from a photograph readers should be able to open at full size. The converter preserves the aspect ratio. Its “Do not enlarge smaller images” option avoids scaling up a source that is already small.

JPG and WebP also allow quality adjustments. After exporting, inspect small text, hair, sharp edges and gradients. A lower setting may reduce the file size while introducing visible artifacts. Quality percentages across different formats are not a shared measurement scale. The quality slider does not have a comparable effect on PNG export.

Transparency and metadata

PNG and WebP can preserve transparent pixels. JPEG has no alpha channel. When my converter exports a JPG, it places transparent areas on a white background. Check that result if the image will later be displayed against a dark page.

Redrawing and re-encoding normally leaves the original EXIF and GPS metadata behind. This is not complete anonymization. A name in a screenshot, a house number in a photograph or other visible information remains part of the image.

The converter is intended for static raster images. It is not a replacement for tools that preserve animations, edit vector artwork or prepare colour-managed print production files.

Why is an output format unavailable in my browser?

A browser may be able to display an image format without being able to export it. My converter therefore tests encoding support and checks the actual type of the generated file.

This matters because the Canvas API can fall back to PNG when a requested format is unsupported. Giving that result a .webp extension would not make it a WebP image. The converter marks unsupported output options accordingly.

Choose an available format or try another current browser if an export is unavailable. For AVIF input, the browser must also be able to decode the source.

Frequently asked questions

Is WebP always smaller than JPG or PNG?

No. The source, dimensions and settings all matter. Compare the displayed file sizes and the visible result. An image that is already heavily compressed cannot be reduced indefinitely.

Does converting JPG to PNG make the photo lossless again?

The PNG stores the pixels it receives without further lossy compression. It cannot reconstruct information lost during earlier JPG compression.

Can I convert AVIF to JPG?

Yes, if your browser can read the AVIF file. Select JPG/JPEG as the output. The converter does not produce AVIF files.

Are my images uploaded?

The selected image files are processed locally in this converter. They are not sent to an upload endpoint for conversion.
