Linux Updates Explained

On Debian, apt update only refreshes package lists. On Arch, pacman -Syu refreshes the databases and upgrades installed packages in one operation. Find the commands for your distribution and see what each step changes.

Update Linux Mint

Use Update Manager for routine updates. Review the list and restart for a new kernel. Set up Timeshift for the system and keep a separate file backup. Follow Mint’s instructions when changing major release or edition. A full-upgrade does not perform that procedure.

  • sudo apt update
    sudo runs APT with administrative permissions. update downloads package indexes. It installs no upgrades.
  • sudo apt upgrade
    upgrade installs available updates and can add dependencies. It does not remove already installed packages.
  • sudo apt full-upgrade
    full-upgrade can remove installed packages to resolve dependencies. Review the list before confirming.

Update Debian 13

Synaptic is a graphical APT option. Stable security updates do not require switching branches. Check prompts about changed configuration files and service restarts. Reboot for a new kernel. Back up files and repository settings and read the Debian release notes before moving to the next stable release.

    sudo runs APT with administrative permissions. update downloads package indexes. It installs no upgrades.
  • sudo apt upgrade

Update Arch Linux

Read Arch News before substantial updates. Review replacements before accepting them and merge .pacnew files deliberately. Partial upgrades, such as syncing the database and upgrading only one package, are unsupported. Reboot after kernel or graphics-stack updates. Keep a rescue medium and current backups.

  • sudo pacman -Syu
    sudo grants administrative rights, -S selects sync, -y refreshes the package database and -u upgrades outdated installed packages.
  • yay
    Only when yay is installed. With no arguments, the helper updates repository and AUR packages. Run as a normal user and review AUR build recipes.

Official instructions

Update Gentoo Linux

The documented workflow uses Portage in a terminal. Read Gentoo News and check USE, slot and license conflicts before confirming. Review configuration changes before merging. Run depclean only after a successful update and after reviewing the dry run. Check bootloader and kernel integration before rebooting. Back up /etc/portage and your files.

  • sudo emaint sync -a
    sudo grants administrative rights. emaint is Portage’s maintenance tool, sync synchronizes repositories and -a selects repositories configured for auto-sync.
  • sudo emerge -avuDN @world
    emerge manages packages. -a asks first, -v is verbose, -u updates, -D follows deep dependencies and -N accounts for changed USE flags. @world covers system and selected packages.
  • sudo emerge --ask --pretend --depclean
    --pretend shows the plan without changes. --ask requests confirmation when acting. Review every proposed removal.
  • sudo emerge --depclean
    --depclean removes packages outside the needed dependency set. Without --pretend it applies the changes.

Official instructions

Update Fedora Linux

GNOME Software or Discover can offer updates depending on edition. dnf upgrade updates packages within the installed RPM release. Review dependencies and removals. A major release change follows Fedora’s system upgrade process. Atomic desktops have separate tools. Reboot for kernel updates.

  • sudo dnf upgrade
    sudo grants administrative rights. DNF resolves dependencies and upgrade updates installed packages from configured repositories.

Official instructions

Update NixOS

Use the channel or flake workflow that matches the current system. Run flake commands in the project directory. Review the lockfile diff before rebuilding. nix profile upgrade updates a separate user profile. Retained generations appear in the boot menu. A new kernel takes effect after reboot. Back up Nix files, lockfile and user data.

  • sudo nixos-rebuild switch --upgrade
    --upgrade updates the inputs used in the channel workflow. switch builds and activates the system and makes it the next boot default.
  • nix flake update
    Updates locked inputs in flake.lock. The flakes feature must be available.
  • sudo nixos-rebuild switch --flake .
    --flake . uses the flake in the current directory. Add #hostname to the reference when selecting a specific configuration.
  • sudo nixos-rebuild switch --rollback
    --rollback activates the previous available system generation. Personal files are outside its scope.

Official instructions

Update CachyOS

Pacman is the usual route. If your installation supplies a graphical package manager, apply the full upgrade there. Check CachyOS and Arch notices as well as your kernel and repositories. Reboot for a new kernel. Check backups or configured snapshots before major changes.

  • sudo pacman -Syu
    sudo grants administrative rights, -S selects sync, -y refreshes the package database and -u upgrades outdated installed packages.
  • yay
    Only when yay is installed. With no arguments, the helper updates repository and AUR packages. Run as a normal user and review AUR build recipes.

Update Ubuntu

Software Updater handles routine system updates. Snaps have their own refresh cycle. Review the APT changes and reboot after a kernel update. Read release notes and back up files before a release upgrade through Software Updater or do-release-upgrade.

  • sudo apt update
    sudo runs APT with administrative permissions. update downloads package indexes. It installs no upgrades.
  • sudo apt upgrade
    upgrade installs available updates and can add dependencies. It does not remove already installed packages.

Update openSUSE Tumbleweed

Tumbleweed moves between distribution snapshots. Use zypper dup for the full transition. Individual graphical package updates do not replace it. Review vendor changes, removals and extra repositories. Reboot after a kernel change and check whether your Btrfs and Snapper setup offers a recovery path.

  • sudo zypper dup
    sudo grants administrative rights. dup is short for dist-upgrade. Zypper reconciles installed packages with the configured repositories.

Official instructions

Update Slackware Linux

Run these as root with the mirror for your branch. Initialize the signing key as documented if needed. Review package lists and .new configuration files. install-new is especially relevant on release upgrades or -current when the ChangeLog adds packages. Use clean-system only after reviewing its list, which may include third-party packages. Check kernel, initrd and bootloader instructions before restarting.

  • slackpkg update
    Updates the package database from the selected mirror.
  • slackpkg install-new
    Offers packages newly added to the distribution.
  • slackpkg upgrade-all
    Lists updates for installed official packages. Review the selections before installing.
