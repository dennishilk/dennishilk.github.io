## 🐧 About the Site

Built using:
- Pure **HTML + CSS + Vanilla JS**
- Custom dark **tech aesthetic**
- Animated **starfield background**
- **Neon-terminal UI** inspired by Zsh / Powerlevel10k
- Offline, **no tracking**, **no analytics**
