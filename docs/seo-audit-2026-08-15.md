# SEO audit and implementation scope — 2026-08-15

This branch applies a site-wide SEO polish without changing observer data, collector logic, or visual behavior.

## Goals

- strengthen Wiesmoor / East Frisia discoverability in German and English
- strengthen Germany-oriented search context on localized pages
- strengthen worldwide / US discoverability for World Observer, Area 51, Space, Linux and Computer Museum content
- remove mixed-language metadata where dedicated localized pages already exist
- make key hub titles and descriptions descriptive rather than implementation-oriented
- add explicit breadcrumb structured data to important deep pages
- add a dedicated image sitemap for local Wiesmoor imagery
- add regression tests for localized metadata, hreflang/canonical pairs, sitemap coverage and structured-data contracts

## Evidence boundary

SEO copy must describe only content that is actually present on the corresponding page. No traffic, ranking, authority, popularity, freshness, live-data or geographic claims are invented for search optimization.
