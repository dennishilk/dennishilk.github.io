Evidence Boundary

EXPORT

Observed

Country codes and the exported cable_count, landing_count, dependency_score, and redundancy_score fields, plus status, timestamp, methodology version, source type, and dataset hash.

BROWSER

Derived

Only transparent arithmetic over those fields: country-field sums and simple history counts such as distinct values, changes, and the current constant run.

NOT EXPORTED

Unknown

Cable identities, landing-site names or coordinates, route geometry, ownership, capacity, traffic, physical condition, outages, and causal meaning. Score values are shown without inventing a percentage scale or qualitative label.

METHOD

Methodology

The page reads only the existing static World Observer latest export and its published history. It does not query cable operators, map providers, network routes, or live infrastructure services. The atlas is an abstract profile layout, not a geographic cable map.
