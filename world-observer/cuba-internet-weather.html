03 / EVIDENCE BOUNDARY

What the export can — and cannot — say

Measured latency, browser-derived numeric context and missing network context remain separate.

Observed

  • Current published average ping time.
  • Published latency history and dates.
  • Current export status and observation time.

Derived

  • Median and quartiles calculated from numeric history points.
  • Current position within the published numeric range.
  • Upper-decile markers calculated from the published series.

Unknown

  • The target identity represented by targets.1 is not named in these dashboard/history exports.
  • Route, provider, ASN, congestion source and packet-level path details.
  • Whether this single exported metric represents country-wide Cuban Internet conditions or user experience.
04 / PROVENANCE

Method & source boundary

No external enrichment is added to this observer-specific view.

Methodology

The current value comes from targets.1.ping.rtt_avg_ms. The barometer maps that value only against the minimum and maximum numeric values in the published history; it is not a quality score. The history panel plots the same exported metric. Median, quartiles, range position and upper-decile markers are presentation-time calculations from those published values. “Weather” describes the visual language only and does not infer meteorology, policy, infrastructure failure or cause.
