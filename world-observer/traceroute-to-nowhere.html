03 / EVIDENCE BOUNDARY

What the export can — and cannot — say

The page keeps observed values, simple derivations and unknown network details separate.

Observed

  • Current published trace count.
  • Published history points.
  • The export supplies observation date and data status.

Derived

  • Value changes are computed from the published series.
  • Distinct values are counted from numeric points.
  • Numeric coverage is calculated from the public history.

Unknown

  • Actual hop sequence, IP addresses and ASNs.
  • Per-hop RTT, packet loss and ownership.
  • Destination outcome, routing intent and the cause of any change.
04 / PROVENANCE

Method & source boundary

No external enrichment is added to this observer-specific view.

Methodology

The current visualization reads the published metrics.trace_count aggregate. One animated lane is drawn per count unit, capped only for presentation if a future value becomes unusually large. Lane order, length and motion are graphic encodings, not measured hops. Historical stability, distinct-value count, change events and numeric coverage are calculated directly in the browser from the published history series.
