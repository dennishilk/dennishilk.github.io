03 / EVIDENCE BOUNDARY

What the export can — and cannot — say

A published index value, browser-derived series statistics and broader Internet interpretation remain separate.

Observed

  • Current published shrinkage score.
  • Published count of countries evaluated.
  • Published history values, dates, statuses and metric names.

Derived

  • Current-series peak is calculated from comparable published points.
  • Distinct values are counted only within the active metric path.
  • Consecutive value changes are calculated from the active series.

Unknown

  • The physical or address-space size of the Internet.
  • Which networks, services or users are affected by a score.
  • Cause, policy, outage mechanism or broader significance of any change.
04 / PROVENANCE

Method & source boundary

This view adds presentation and simple arithmetic, but no external enrichment or causal interpretation.

Methodology

The current value is read from global.global_shrinkage_index. The aperture width is normalized only against the maximum numeric value observed within that same metric path and must not be read as a percentage. History points with another metric_name remain visible as a separate legacy segment instead of being treated as directly comparable. Statistics are calculated in the browser from the published history export.
