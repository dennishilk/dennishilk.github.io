    03 / DOCUMENTATION

    Methodology

    The existing reachability collector and dashboard logic are unchanged. Public-source panels independently request catalogue metadata or imagery from Copernicus Data Space and NASA GIBS and keep those sources separate from the observer metric.

    04 / PROVENANCE

    Sources

    Observer telemetry uses the existing local World Observer exports. Location context uses EOxCloudless Sentinel-2 imagery; satellite-pass metadata comes from the Copernicus Data Space STAC catalogue; thermal-anomaly imagery comes from NASA Earthdata GIBS.
