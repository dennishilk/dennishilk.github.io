Frequently asked questions

Are my images uploaded anywhere?

No. This page has no image-upload workflow. Your selected files are processed locally in the browser and the generated files are exposed to you as temporary local download URLs.

Why might AVIF not work on an older browser?

AVIF input depends on the browser's own image decoder. If the browser cannot decode the file, the converter will report an error instead of sending it elsewhere.

What happens to transparency?

PNG and WebP output can keep transparent pixels. JPEG has no alpha channel, so transparent areas are flattened onto a white background.

Is metadata preserved?

Usually not. The image is redrawn into a canvas and encoded again, so original EXIF and GPS metadata is generally not copied into the new file.
