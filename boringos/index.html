BoringOS

An independent experimental desktop operating system built from scratch — not Linux, not BSD, and not a wrapper around another kernel. BoringOS now has its own kernel, Ring3 userspace, persistent storage stack, display service, native BoringWM and a real graphical terminal.boring is not a bug. it's the entire operating system now.
