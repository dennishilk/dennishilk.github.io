Built from scratch

What makes BoringOS an independent operating system?

BoringOS is not a Linux distribution, BSD variant or desktop shell on top of another OS. Limine boots it, but the kernel, userspace, filesystem and desktop stack are BoringOS components.

BoringKernel

Its own x86_64 kernel provides memory management, scheduling, process address spaces, Ring 3, syscalls, ELF64 userspace, IPC and hardware-facing subsystems.

BoringFS

Its own writable filesystem has a formatter, validator, boringfsck, kernel mount support and a physically proven persistent USB-root lifecycle.

Native C userspace

boring-init, boring-display, the shell, PTYs and native applications run on BoringOS's own syscall and VFS layers rather than a Linux or BSD userspace.

BoringWM desktop

The native display service and BoringWM compose the desktop themselves. BoringTerminal, BoringEdit and BoringFiles run without X11 or Wayland underneath.

07 · Current limits

The remaining rough edges are visible — and useful.

The physical machine is now exposing exactly which bootstrap assumptions should be removed next.

Keyboard

Held USB keys do not typematically repeat yet, and the current keymap is effectively ENG/US rather than a finished German layout.

Graphics

1920×1080 is physically tested, but multiple windows at that resolution can still be demanding. Native 3440×1440 and GPU acceleration are not implemented.

Memory

Cthulhu has 32 GiB installed and BoringOS detects it through SMBIOS; making practical use of the full capacity remains future work.

System breadth

No networking, audio, NVMe or SMP runtime yet, and no native GPU driver. BoringOS still prefers truthful boundaries over pretend support.

FAQ · Independent OS

BoringOS in plain terms.

The short answers to the questions people usually ask when they see a hobby operating system with its own kernel and desktop.

Is BoringOS Linux?

No. BoringOS is not a Linux distribution and does not use the Linux kernel. It has its own x86_64 kernel, BoringKernel.

Is BoringOS based on BSD?

No. It is not BSD and is not a wrapper around another operating-system kernel.

What language is BoringOS written in?

BoringOS-developed system components are written primarily in C, with small isolated x86_64 assembly where the architecture requires it.

Does it have its own kernel and filesystem?

Yes. BoringKernel provides the kernel foundation and BoringFS is the writable native filesystem used by the physical USB-root system.

Does BoringOS run on real hardware?

Yes. It is physically tested on Cthulhu; M68 ran the native software-rendered desktop at 1920×1080 with real USB keyboard and mouse input.

Is it a Windows, Linux or macOS replacement?

Not today. BoringOS is an experimental independent operating-system project, not a claimed daily-driver replacement. Its missing areas are documented explicitly.
